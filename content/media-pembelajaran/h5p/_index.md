Halaman ini adalah wadah untuk semua konten media pembelajaran berbasis H5P.

Cara cepat menambah konten baru:

1. Buat konten baru dengan archetype H5P.
2. Isi `h5p_url` pada front matter.
3. Tambahkan deskripsi pembelajaran di bawah shortcode.

Contoh perintah:

```bash
hugo new --kind h5p media-pembelajaran/h5p/nama-media.md
```
